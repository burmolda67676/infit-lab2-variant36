# Лабораторная работа №2 — вариант 36

Обработка изображений в иерархической файловой системе.

Методы: Unsharp Masking (повышение резкости) и автоконтраст, последовательно.

## Запуск

```powershell
cd Lab2_Media
py -m pip install -r requirements.txt
py main.py
```

Введите `image1.jpg`. Результат: `data/output/result.jpg`, журнал: `logs/history.txt`.

Папки создаются средствами ОС, не программой Python. Для `image2.png` в Windows установите атрибут «Только чтение», а для `data/input` настройте группу «Все» на чтение и выполнение, без записи и изменения. Git не переносит NTFS-разрешения и атрибут ReadOnly; их нужно установить на своём компьютере.

В условии есть неточность: ReadOnly разрешает чтение. Для демонстрации запрошенной ошибки программа явно вызывает PermissionError при наличии этого атрибута; реальная ошибка доступа ОС также перехватывается. Оба входных файла содержат предоставленное фото в двух форматах.

Проверены успешная обработка, ошибка доступа по учебному правилу и отсутствующий файл.
